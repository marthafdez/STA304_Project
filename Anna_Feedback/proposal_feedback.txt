Simple and multiple linear regression
You plan to use multiple linear regression, so you do not need simple linear regression as well. Simple linear regression is a special case of multiple linear regression. If you see an effect in the simple model that disappears in the multiple model, that tells you the effect is not strong once the other covariates are in the model.

Model selection
Please state exactly which model selection method you will use. The method matters, so naming it is better than leaving it general.

VIF and multicollinearity
You do not need a VIF check to deal with collinearity. Multicollinearity is not a problem that needs curing here. It matters in machine learning, where the goal is accurate prediction. In this course we are not predicting anything, and we are not running a causal experiment. We are describing associations, trends, and patterns among the students in our population, so multicollinearity does not get in the way of that. There is published literature on why multicollinearity is not a disease that needs curing if you want to read more (feel free to email me if you really care)

Gender question
Please include an "other" option. It may not come up often in a stats context, but it can happen, so it is safer to include it.
